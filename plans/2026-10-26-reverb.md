# Reverb

## Goal

Put the pan in a space. The prototype (`scripts/reverb_demo.py`, renders in `scripts/renders/reverb/`) voiced four rooms as a feedback delay network; this moves it into the engine, the settings pane and the score format.

## Design

- **Engine** (`engine/morphion.h/.cpp`): `Reverb`, a feedback delay network as in the prototype: 12 ms pre-delay, six early reflections alternating sides (times scaled by room size), eight delay lines through a Householder matrix with a per-line loss for the decay time and a one-pole low-pass (damping); left-column notes enter from the left, right from the right, and the tail is read with different signs per side so it is wide. `kReverbs` holds dry, small, medium, hall and stairwell with the prototype's t60, size, wet level and damping. It processes the whole mix (notes, attack, Gu, slap) before the gain and limiter. `Engine::reverb` is an atomic read once per block; a change fades the old room out, clears it and fades the new one in (no allocation: the lines are sized for the largest room in `configure`). Dry skips the stage, so the dry sound is unchanged bit for bit.
- **App**: a Reverb row of buttons under Key, where the layout row was (Dry, Small room, Medium room, Hall, Stairwell); live, saved with the other settings.
- **Scores**: header key `reverb = dry|small|medium|hall|stairwell`, default `dry`; recordings write it. It is not a `set` setting.

## Decisions & ownership

| Decision | Tag | Notes |
|---|---|---|
| Dry by default | user-owned, surfaced | User's call; the out-of-the-box sound is unchanged. |
| Called Reverb; a row of buttons in increasing decay, where the layout row was | user-owned, surfaced | User's call, after trying a detented slider. |
| The four rooms are the prototype's, unchanged | AI-owned, default | The user hasn't compared them by ear yet; `scripts/renders/reverb/engine_*.wav` are the engine's versions for that. |
| Tail read from the delay lines' outputs (standard FDN) rather than the prototype's block-delayed line inputs | AI-owned, defended | Equivalent tail without the prototype's block artifact; decays measure 0.42 / 0.84 / 1.87 / 2.58 s (prototype 0.36 / 0.75 / 1.7 / 2.45; nominal 0.5 / 1 / 2.2 / 3, the damping shortens them). |
| Changing the reverb live fades the old room out over 20 ms, clears it and fades the new one in | AI-owned, defended | Lengths change with the room, so the old tail can't carry over; clearing it at once clicked (code review). Before a piece starts (`configure`) the room is set at once, so scores render as before. |
| `reverb` is header-only in scores | AI-owned, default | Settings can't change during a recording; a mid-piece room change has no use yet. Adding `set reverb` later is additive. |

## What this changes elsewhere

- **Score format**: a new header key, before 0.3 ships. Older 0.3-dev builds refuse files that carry it (they don't know the key).
- **CPU**: eight delay lines and six taps per sample when a room is on; nothing when dry.
- **Parity checks**: `multi_field.py --check` renders dry, unaffected. Dry renders of both scores are byte-identical to the previous build.
- **Slider layout** (alongside): every slider's track now runs the full width under its label and value.
