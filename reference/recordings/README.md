# Reference recordings

Handpan recordings from Freesound, used to compare against the model (analysis only, never as samples). Each is Freesound's HQ preview (128 kbps MP3), decoded to 16-bit WAV, so detail above ~16 kHz is lost.

| File | Source | Licence | Contents |
|---|---|---|---|
| `fs426794_handpan.wav` | [tarane468, 426794](https://freesound.org/people/tarane468/sounds/426794/) | CC BY 4.0 | Scale walk, one strike every ~1.5 s: A#3, C4, D4 at 4.80 s, F4, G4, A4, C5, D5. Sounds knuckle-struck, not finger pads; not representative |
| `fs547845_soft_touch.wav` | [GAMEDRIX974, 547845](https://freesound.org/people/GAMEDRIX974/sounds/547845/) | CC BY-NC 3.0 | One soft strike, C4 area; about 3 s to −60 dB, then gated to silence at about 4.7 s |
| `fs556254_hang_excerpt.wav` | [mstamp, 556254](https://freesound.org/people/mstamp/sounds/556254/) (from [Skjor1, 321776](https://freesound.org/people/Skjor1/sounds/321776/)) | CC0 | Hang excerpt, normalised; one clear A3 strike at 2.54 s |
| `fs493864_shaktipan_csharp.wav` | [GeorgeNaimeh, 493864](https://freesound.org/people/GeorgeNaimeh/sounds/493864/) | CC0 | **Primary reference.** Shaktipan (nitrided steel, maker Andrea Tonella), just after tuning; finger-pad strikes on F#4 (2.21 s) and G#4 (2.53 s) |
| `fs520472_akebono_dry.wav` | [deleted user, 520472](https://freesound.org/people/deleted_user_4087401/sounds/520472/) | CC0 | E Akebono handpan, dry; a rhythmic pattern on E3, F#4, G4, B4, strikes 0.5–1 s apart |
| `fs587418_tones.wav` | [GAMEDRIX974, 587418](https://freesound.org/people/GAMEDRIX974/sounds/587418/) | CC0 | "Handpan tones"; quiet, no clear strike onsets |

Pitches are from an FFT of each strike, not from the uploaders. The strongest peak can be the octave, not the fundamental.
